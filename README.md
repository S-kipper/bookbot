## Bookbot

BookBot is a simple Python program that analyzes a text file (ebook) and provides useful statistics such as word count and character frequency.

This project was built as part of the **Boot.dev Python course** and is intended as a beginner-friendly introduction to Python scripting and text analysis.

---

# Features

- Counts the total number of words in a book  
- Counts how often each character appears  
- Outputs a clean, readable report  
- Simple and beginner-friendly Python code  

---

# Requirements

- Python **3.8+**
- No external libraries required

---

# Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/bookbot.git
```

Navigate into the project directory:

```bash
cd bookbot
```


# Usage

Place your text file (ebook) inside the project directory
(for example: book.txt)

Run the program:

```bash
python main.py
```

The program will analyze the text and print a report to the terminal.
